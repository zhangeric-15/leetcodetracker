# LeetCode Tracker

> A useful full-stack app to track your LeetCode problem-solving progress, categorize problems, and visualize your learning.

---

## Technologies Used
- **Frontend:** React, React Context, HTML/CSS
- **Backend:** Node.js, Express.js w/Mongoose, MongoDB (Atlas)
- **Authentication:** JWT (JSON Web Tokens)
- **Other Tools:** Postman, Git, Visual Studio

---

## Features
- User login and sign-up logic.
  -   User authentication with persistent sessions through JSON Web Tokens (JWT) stored in cookies.
- Log, edit, and delete solved problems.
- Categorize problems by difficulty, understanding, date solved, and custom topics.
- Create, Edit, and Delete custom topics. Specifically, users can change the color of their topic tags to any unique color!
- Responsive SPA design through React.

---

## Upcoming Features
- Sort and filter problems by name, difficulty, or date solved.
- Search for problems.
