# LeetCode Tracker

> A simple full-stack app to track your LeetCode problem-solving progress, categorize problems, and visualize your learning.

---

## Technologies Used
- **Frontend:** React, React Context, HTML/CSS
- **Backend:** Node.js, Express.js w/Mongoose, MongoDB
- **Authentication:** JWT (JSON Web Tokens)
- **Other Tools:** Postman, Git, Visual Studio

---

## Features
- Log, edit, and delete solved problems.
- Categorize problems by difficulty, understanding, date solved, and custom topics.
- Create, Edit, and Delete custom topics. Specifically, users can change the color of their topic tags to any unique color!
- User authentication with persistent sessions through JWT stored in cookies.
- Responsive SPA design through React.
